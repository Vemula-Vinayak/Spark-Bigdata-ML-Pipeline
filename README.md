# Distributed Machine Learning with PySpark

## Overview
This project demonstrates an end-to-end distributed machine learning pipeline using PySpark. It focuses on scalable data preprocessing, feature engineering, and model training using Spark ML.

## Objectives
- Load and process large-scale dataset using Spark
- Perform distributed data transformations
- Encode categorical features
- Assemble feature vectors
- Train and evaluate ML models using Spark ML

## Technologies Used
- PySpark
- Spark ML
- Python
- Distributed Data Processing

## Key Learning Outcomes
- Building scalable ML pipelines
- Handling large datasets efficiently
- Distributed feature engineering
- Model training in a Spark environment

## How to Run
1. Install PySpark
2. Launch Jupyter Notebook
3. Run `spark_ml_pipeline.ipynb`
